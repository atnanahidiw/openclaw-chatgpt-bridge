# Provider logos

Source: [Simple Icons](https://simpleicons.org) (`simple-icons` npm package). The icon
files are CC0. The trademarks are not.

These logos are used **nominatively**, to say which platforms this bridge deploys to.
That is not a claim of endorsement, sponsorship, or affiliation by Amazon, Microsoft,
Google, or DigitalOcean.

Each file carries its owner's published brand colour and is otherwise unmodified: no
recolouring, no reproportioning, no added effects. That matters for AWS in particular,
whose [trademark guidelines](https://aws.amazon.com/trademark-guidelines/) forbid altering
the mark in any way, including colour and proportion.

| File | Brand | Colour |
|---|---|---|
| `amazonwebservices.svg` | Amazon Web Services | `#FF9900` |
| `microsoftazure.svg` | Microsoft Azure | `#0078D4` |
| `googlecloud.svg` | Google Cloud | `#4285F4` |
| `digitalocean.svg` | DigitalOcean | `#0080FF` |

Note: at the time of adding these, AWS and Azure were **absent from the Simple Icons
metadata** while their SVGs were still served. That project removes brands on trademark
request, so treat those two as the likeliest to need replacing with plain text later.
